Write your first program in the next 5 minutes.

Plainly is a programming language that reads like English. This page takes you from "I've never coded" to "I built a website" — one small step at a time.

Step 0 — Try it right now (nothing to install)

Open The Book in your browser. Almost every example has a ▶ Run button that runs the real language right on the page. Try this one — change the name, press Run again:

say "Hello, world!" say "My name is Plainly" say 2 + 2

That's a real program. If you can type that, you can program.

Step 1 — Put it on your computer

1

Install Node.js

Go to nodejs.org, download the "LTS" version, click next-next-next. You only do this once.

2

Get Plainly

Download the project folder (or git clone it), open a terminal inside it, and run:

npm install npm run build
3

Say hello from your own machine

Make a file called hello.pl with one line in it:

say "Hello, world!"

Then run it:

node dist/cli.js run hello.pl

You should see Hello, world!. That's it — the language lives on your computer now.

💡

What is a terminal? It's the black window where you type commands. On Windows it's "PowerShell", on Mac "Terminal". To open one inside a folder: right-click the folder → "Open in Terminal".

Step 2 — Learn the 6 words that do 90% of everything

Plainly has 16 keywords total. These six are the ones you'll use constantly:

say set if for each repeat function
# say = show something say "I am learning to code" # set = remember something in a box set my_age = 25 say my_age # if = choose if my_age >= 18: say "I am an adult" # for each = do it for every item set snacks = ["chips", "cookies", "fruit"] for each snack in snacks: say "I like " + snack

Type these into hello.pl and run it. Change things. Break things. The Book explains every line with pictures.

Step 3 — Meet your first error (it's friendly)

Sometimes the computer doesn't understand you. In most languages that looks scary. In Plainly it looks like this:

PL-002 at line 2, column 5: You tried to use 'naem', but it doesn't exist yet. say naem ^^^^ Hint: Did you mean 'name'?

Read it slowly: what (name doesn't exist), where (line 2, with the little arrow), and how to fix it (the hint). Every error has a code like PL-002 — the Book's chapter 14 lists them all in plain words.

🎓

Errors are not failure. They are the computer asking a question. Answer it, run again, move on. Every programmer reads errors all day.

Step 4 — Build a real website

Now the fun part. Describe a website in one file:

app "My Bakery" database Cake: name: text price: money page "Menu": title "Our cakes" show Cake form "Add a cake" from Cake: field name: text field price: number page "About": title "We love cake"

Then run one command:

node dist/cli.js build bakery.pl -o my-bakery

You now have a folder with:

  • a database (schema.sql — the tables for your cakes)
  • an API server (server/ — saves and serves your data)
  • a website (client/ — real pages with a working form)

Run it (you'll need the free PostgreSQL database — the generated README walks you through it step by step):

# 1. create the database tables createdb my_bakery psql -d my_bakery -f my-bakery/database/schema.sql # 2. start the server cd my-bakery/server && npm install && npm run dev # 3. in a second terminal, start the website cd my-bakery/client && npm install && npm run dev

Open http://localhost:5173 — your bakery website, with a working form that saves cakes. You described it in 14 lines. The generated code is ordinary code you can open, read and change.
